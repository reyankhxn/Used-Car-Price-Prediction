# 🚗 Used Car Price Prediction System

## Overview

A Machine Learning web application that predicts the resale value of used cars based on vehicle specifications such as manufacturing year, present price, kilometers driven, fuel type, seller type, transmission type, and ownership history.

## Features

* Predicts used car selling prices
* Interactive Streamlit dashboard
* Random Forest Regression model
* Data preprocessing and feature engineering
* Real-time price prediction

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-Learn
* Streamlit
* Joblib

## Machine Learning Model

* Random Forest Regressor
* R² Score: 0.96
